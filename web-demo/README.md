# Demo AI Ψηφιακού Διδύμου

Ένα νέο πρωτότυπο περιβάλλον για την εμπειρία του AI ψηφιακού διδύμου. Χρησιμοποιεί HTML, CSS και JavaScript, χωρίς Streamlit.

## Εκτέλεση στον υπολογιστή σου

Άνοιξε το `index.html` σε ένα πρόγραμμα περιήγησης. Για τοπική ανάπτυξη, ξεκίνησε έναν απλό διακομιστή από αυτόν τον φάκελο:

```bash
python3 -m http.server 8000
```

Έπειτα άνοιξε τη διεύθυνση http://localhost:8000.

Η αρχική οθόνη και το όνομα που επέλεξες αποθηκεύονται στο πρόγραμμα περιήγησης. Για να ξαναδείς την αρχική διαδικασία, καθάρισε τα αποθηκευμένα δεδομένα αυτού του ιστοτόπου.

## Τι περιλαμβάνει τώρα το demo

Αρχική οθόνη → επιλογή ονόματος → πλοήγηση σε πέντε ενότητες → σύντομες παρουσιάσεις των ενοτήτων.

Στην ενότητα Προσθήκη μπορείς να επιλέξεις ένα ή περισσότερα αρχεία `.txt` έως 1 MB το καθένα. Το demo διαβάζει και αποθηκεύει το περιεχόμενό τους τοπικά στον browser, εμφανίζει επιβεβαίωση και επιτρέπει να δεις ή να αφαιρέσεις κάθε αρχείο. Για τώρα, τα αρχεία δεν αναλύονται ακόμη ώστε να ενημερώσουν αυτόματα το Προφίλ ή τον Γράφο.

Οι ενότητες Καθοδήγηση, Γράφος και Προφίλ παραμένουν προσχέδια διεπαφής. Η λειτουργία τους θα προστεθεί στα επόμενα βήματα.
