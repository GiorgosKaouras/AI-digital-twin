# Echo — AI Digital Twin Demo

Το Echo είναι πρωτότυπο ψηφιακού διδύμου για έναν χρήστη. Διαβάζει αρχεία TXT/PDF, οργανώνει επιβεβαιωμένα στοιχεία προφίλ και σχέσεις, αναζητά σχετικά αποσπάσματα και απαντά με εμφανείς πηγές. Το περιεχόμενο του φακέλου sample-data είναι αποκλειστικά συνθετικό.

## Εκκίνηση

Χρειάζεται Docker Desktop ή Docker Engine με Docker Compose v2. Από τον φάκελο του project τρέξε:

    docker compose up --build

Άνοιξε http://127.0.0.1:8000. Στην πρώτη εκκίνηση κατεβαίνουν δύο επίσημα μοντέλα Ollama, περίπου 1.2 GB συνολικά. Η εφαρμογή περιμένει να είναι έτοιμα πριν ξεκινήσει. Δεν απαιτείται OpenAI API key. Τα μοντέλα παραμένουν στο Docker volume ollama_data.

Το προεπιλεγμένο chat χρησιμοποιεί qwen3:0.6b και τα embeddings το qwen3-embedding:0.6b. Τα μεγέθη τους είναι περίπου 523 MB και 639 MB αντίστοιχα ([Ollama Qwen3](https://ollama.com/library/qwen3), [Ollama Qwen3 Embedding](https://ollama.com/library/qwen3-embedding)). Η εξαγωγή κειμένου και το OCR σαρωμένων PDF εκτελούνται τοπικά με OCRmyPDF/Tesseract σε ελληνικά και αγγλικά.

Για να σταματήσεις το demo χωρίς να χάσεις τα αρχεία σου, πάτησε Ctrl+C. Η βάση και τα uploads βρίσκονται στο backend/data, ενώ τα μοντέλα διατηρούνται στο ollama_data.

## Πρώτη γνωριμία και ζωντανό demo

Σε καθαρό browser, το Echo ανοίγει τα welcome slides, ζητά όνομα και κάνει πέντε αρχικές ερωτήσεις. Στο τέλος εμφανίζει σύνοψη για έλεγχο, προαιρετικό βήμα CV και διαφάνεια ολοκλήρωσης. Η συμπλήρωση CV μπορεί να παραλειφθεί. Οι απαντήσεις στις αρχικές ερωτήσεις είναι επιλογές του χρήστη, αποθηκεύονται στο προφίλ και διαγράφονται από τις Ρυθμίσεις όταν γίνει επανεκκίνηση demo.

Για συνεπή επίδειξη, βάλε ως όνομα «Ελένη Παπαδοπούλου» και ακολούθησε τα βήματα στο DEMO_RUNBOOK.md. Πρόσθεσε τα TXT από το sample-data στην ενότητα Προσθήκη. Στον Γράφο, επέλεξε τον φάκελο sample-data/connections για να εισαγάγεις τις συνθετικές συνδέσεις. Οι προτάσεις προφίλ και σχέσεων χρειάζονται έλεγχο και έγκριση πριν χρησιμοποιηθούν ως επιβεβαιωμένα στοιχεία.

Το κουμπί «Βρες σύνδεση με τη θέση εργασίας» εμφανίζει τεκμηριωμένη διαδρομή και δημιουργεί προσχέδιο email .eml. Δεν στέλνει μήνυμα. Τα demo emails χρησιμοποιούν δεσμευμένο domain .example.test.

## Ενότητες και αρχιτεκτονική

- Καθοδήγηση: FastAPI δρομολογεί ερώτημα σε στοιχεία προφίλ, έγγραφα ή εγκεκριμένες σχέσεις. Η ανάκτηση χρησιμοποιεί embeddings και SQLite. Οι απαντήσεις εμφανίζουν το αρχείο ή την εγγραφή προφίλ που τις στηρίζει.
- Προσθήκη: αποθήκευση TXT/PDF, τοπική εξαγωγή κειμένου/OCR, τεμαχισμός κειμένου και δημιουργία embeddings. Το αρχικό αρχείο παραμένει στα Documents του demo.
- Προφίλ: επεξεργασία, έγκριση, απόρριψη ή διαγραφή προτάσεων και ρυθμίσεις ύφους απάντησης.
- Γράφος: άνθρωποι, οργανισμοί και σχέσεις με πηγή και απόσπασμα. Νέες σχέσεις μένουν προτάσεις μέχρι την έγκριση.
- Frontend: στατικά HTML, CSS και JavaScript. Backend: FastAPI και SQLite. Τοπικό μοντέλο: Ollama. Η SQLite, τα chunks, τα embeddings, τα uploads και το ιστορικό συνομιλίας αποθηκεύονται τοπικά.

Το Echo δεν κάνει fine-tuning ούτε ισχυρίζεται ότι αναπαράγει πλήρως την προσωπικότητα κάποιου. Το persona model είναι επιθεωρήσιμο και βασίζεται σε ρητές απαντήσεις και εγκεκριμένα στοιχεία, ενώ η ανάκτηση εγγράφων προσθέτει τεκμηριωμένο πλαίσιο. Ο ιδιοκτήτης μπορεί να δει, να διορθώσει ή να διαγράψει τα στοιχεία.

## Προαιρετική λειτουργία Cloud

Η τοπική λειτουργία είναι η προεπιλογή. Για OpenAI χρειάζεται API key και ενδέχεται να υπάρξει χρέωση. Μην προσθέσεις το key στον κώδικα ή στο Git. Το αρχείο .env εξαιρείται από Git και Docker build context. Συμπλήρωσε τοπικά τις ρυθμίσεις του .env.example και επίλεξε Cloud με OpenAI από την ενότητα Προσθήκη. Τα κείμενα που χρειάζονται για embeddings, chat ή εξαγωγή προτάσεων αποστέλλονται στην OpenAI.

## Όρια και προστασία δεδομένων

Το demo είναι για έναν τοπικό χρήστη. Δεν έχει login, πολλαπλούς λογαριασμούς ή απομόνωση δεδομένων μεταξύ χρηστών. Το Compose εκθέτει την εφαρμογή μόνο στο 127.0.0.1· μην την εκθέτεις απευθείας στο δίκτυο ή στο Internet. Μην προσθέσεις πραγματικά στοιχεία τρίτων χωρίς άδεια. Τα αρχεία με οδηγίες προς το AI αντιμετωπίζονται ως μη έμπιστο περιεχόμενο.

Το .gitignore και το .dockerignore εξαιρούν το .env και το backend/data, όπου αποθηκεύονται η βάση και τα uploads. Πριν από υποβολή έλεγξε ότι δεν προστέθηκαν χειροκίνητα προσωπικά αρχεία ή κλειδιά. Η επανεκκίνηση demo από τις Ρυθμίσεις διαγράφει οριστικά τα τοπικά δεδομένα της εφαρμογής.

## Αξιολόγηση και παράδοση

Το DEMO_RUNBOOK.md περιέχει σενάριο επίδειξης, ερωτήσεις με αναμενόμενες απαντήσεις και λίστα ελέγχου πριν από την υποβολή. Για έλεγχο retrieval άνοιξε http://127.0.0.1:8000/?retrieval-debug=1. Το panel δείχνει τα κορυφαία chunks, τα scores και ποια αποσπάσματα επιλέχθηκαν. Το end-to-end σύνολο δέκα ερωτήσεων εκτελείται με ενεργό Ollama και προσωρινή βάση: .venv/bin/python backend/evaluate_routing.py. Ο evaluator φορτώνει μόνο τα συνθετικά αρχεία του sample-data και δεν αντιγράφει ή αλλάζει την κανονική βάση.

Το project καλύπτει λειτουργικό πρωτότυπο, επιθεωρήσιμο persona model, ροή από δεδομένα σε απαντήσεις με πηγές και επεξήγηση ιδιωτικότητας. Οι περιορισμοί της υλοποίησης αναφέρονται ρητά: πρόκειται για prototype ενός τοπικού χρήστη, όχι για ασφαλές multi-user προϊόν ή πλήρη ψηφιακή αναπαραγωγή.
